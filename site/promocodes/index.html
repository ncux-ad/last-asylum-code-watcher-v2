Промокоды Last Asylum: Plague

Как ввести промокод 🍎 на iPhone — только так

На Android код можно ввести и в самой игре, но способ ниже универсальный и работает на обеих платформах. На iPhone ввести код в самой игре нельзя — получить подарок можно только через сайт.

  1. Откройте сайт активации: gevents.globallap.com/gamecode
  2. Войдите по одноразовому паролю (OTP)
  3. Введите свой игровой ID
  4. Введите одноразовый пароль
  5. Выберите свой сервер
  6. Выберите персонажа
  7. Введите промокод
  8. В игре откройте Почту персонажа — там будет подарок
