# Roadmap сайта альянса `_ФенNкс_` [FNX]

Что уже сделано и куда двигаться дальше. Формат — как `RUNBOOK.md`: рабочий документ, редактируется по ходу дела, не публичная страница.

## Готово (2026-09-03)

- Заглушка главной (`site/index.html`) + `/promocodes/` (реальные данные радара, автообновление раз в 2 часа через `senko`).
- Реальные ассеты альянса из игры: знамя `[FNX]`, атмосферный фон, фавикон — не нарисованные заглушки.
- Написание клана везде выверено по игре: `_ФенNкс_` [FNX].
- Инструкция по активации промокодов (с акцентом на iPhone) — свёрнута, на обеих страницах.
- Два домена-зеркала: `fenix-clan.ru` и `fenix-clan.online`, оба на HTTPS одним сертификатом.
- Аналитика — GoatCounter (общий счётчик с GitHub Pages дашбордом, см. `RUNBOOK.md`).
- Хостинг self-hosted (`hosting_vds`), деплой руками через `scp` (см. RUNBOOK → «Публичный сайт»).
- Блок «как вступить в альянс» на главной (требования из игры, контакт — без ников: «Лидеру или R4», через игровой поиск/список альянсов — без прямой ссылки на внутренний чат).

## Фаза 1 — контент, который уже анонсирован в подвале главной

Сейчас в `.soon` висит обещание: «гайды · состав клана · чат». Три страницы-кандидата:

- [ ] **Состав клана** (`/roster/` или раздел на главной) — лидер, требования вступления, число участников/мощь. Источник данных — тот же скриншот экрана альянса, что дал знамя; без игрового API это будет **вручную обновляемая** статичная страница, не автоматика (как и promo-верификация — честно, не выдаём эвристику за факт). Нужно от вас: актуальный текст требований + разрешение публиковать никнейм лидера.
- [ ] **Гайды** — по факту создания контента (кто пишет: вы/участники клана). Технически — ещё один статичный `site/guides/...` в том же стиле, без новой инфраструктуры.
- ~~Чат / связь с кланом~~ — **отменено.** Внутренний чат приватный намеренно: это способ отличить реальных участников клана от посторонних при вступлении, публичная ссылка эту функцию убивает. Вместо неё сделан блок «как вступить» (см. «Готово» выше) — требования + «пишите Лидеру или R4 в игре», без прямой ссылки наружу.
  - Возможная будущая замена самого приёма заявок (озвучена, не в работе): **Telegram-бот для заявок** — принимает заявку/игровой ID с сайта, вручную или полуавтоматически проверяет, что человек реально подал заявку/состоит в клане (то же самое, что сейчас делает Лидер/R4 руками), и только тогда выдаёт ссылку на закрытый чат. Технически отдельный сервис (не радар) — свой бот-токен, вероятно свой процесс на `senko` или `hosting_vds` рядом с существующими. Не начинаем без отдельного запроса — это по объёму отдельный проект, не пункт «на один вечер».

## Фаза 2 — SEO и шаринг (дёшево, эффект сразу)

- [ ] `sitemap.xml` + `robots.txt` в `site/` — сейчас их нет, поисковики индексируют сайт вслепую.
- [ ] Open Graph / Twitter Card мета-теги (`og:title`, `og:image` — знамя или hero-арт, `og:description`) — сейчас ссылка на fenix-clan.ru в Discord/Telegram разворачивается без превью.
- [ ] `<link rel="canonical">` на обеих страницах — у нас два домена-зеркала с одинаковым контентом, без canonical поисковик может решить, что это дубли, и хуже ранжировать оба.

## Фаза 3 — когда страниц станет больше трёх

- [ ] Общая шапка/навигация вместо одной ссылки «← _ФенNкс_» — пока страниц две, отдельный компонент не нужен, но при добавлении гайдов/состава станет тесно.
- [ ] Вынести общие CSS-токены (`:root{--bg...}`) в один файл вместо копipaste между `index.html`/`promocodes/index.html` — сейчас правка палитры требует править в двух местах (уже один раз забыли — можно упустить снова).

## Фаза 4 — не горит, но стоит держать в уме

- [ ] Мониторинг аптайма `fenix-clan.ru`/`.online` (uptime-бот в Telegram или простой cron+curl на `senko`) — сейчас узнаем о падении сайта только вручную зайдя проверить.
- [ ] Напоминание на дату истечения сертификата (certbot автопродление настроено, но проверить, что таймер реально сработал, стоит хотя бы раз).
- [ ] Периодически смотреть в GoatCounter — какие страницы реально смотрят, стоит ли Фаза 1 расставлять в другом порядке.

## Не в фокусе (сознательно)

- Игровой API/автоматическая синхронизация состава — как и с промокодами, это требует чужого логина на регулярной основе; не делаем по той же причине, что и авто-редемпшн (см. README → «Важная оговорка»).
- Мультиязычность — аудитория русскоязычная, домены `.ru`/`.online` тоже про это говорят.
